## 🎯 Current Research

### Layout-Aware OCR in Black Digital Archives
*With Dr. Christopher L. Dancy • IEEE ISTAS 2025*

**The Challenge:** Historical Black archives contain invaluable cultural heritage, but standard OCR systems fail spectacularly on these documents. Why? They're trained on modern, standardized texts—not the diverse layouts, fonts, and formats found in historical materials.

**Our Approach:** We developed an **unsupervised evaluation framework** that doesn't require expensive ground-truth annotations. This allows us to assess OCR performance on real historical documents and identify where systems are failing underserved communities.

**Impact:** Creating more accessible digital archives and exposing biases in document AI systems.

- Synthesized 40+ sources across psychology, sociology, and computer science

### Reinforcement Learning Web Agents
*MiniWob++ • Gymnasium • OpenCV • OCR*

Trained autonomous agents to interact with web interfaces using reinforcement learning:
- Implemented 3 task-specific agents (circle-center, click-checkboxes-soft, identify-shape)
- Built evaluation harness measuring success rate and steps-to-completion
- Explored state representations combining visual features and DOM elements

**Key insight:** Combining pixel-based and structured representations significantly improves sample efficiency.

---

### Workflow-Guided Exploration
*DOMNet • REINFORCE • Imitation Learning*

Investigated how human demonstrations can guide RL agents learning complex web navigation:
- Recorded expert demonstrations across multiple workflows
- Trained agents using workflow-guided exploration vs. rule-based baselines
- Analyzed joint attention patterns between human and agent

**Result:** Workflow-guided agents learned 3x faster than pure RL baselines.

## 🔬 Research Philosophy

I believe the best research:
1. **Solves real problems** for real people
2. **Questions assumptions** baked into existing systems
3. **Bridges disciplines** (CS + cognitive science + sociology)
4. **Ships working code** that others can build upon

My industry background taught me that **research impact comes from implementation**—not just ideas.
